ข้อกำหนดการให้บริการ

FlowLanding Co. — ปรับปรุงล่าสุด: 26 สิงหาคม 2569

การเข้าใช้งานเว็บไซต์ flowlanding.co หรือใช้บริการใดๆ ของ FlowLanding ถือว่าคุณยอมรับข้อกำหนดการให้บริการฉบับนี้ กรุณาอ่านให้เข้าใจก่อนใช้บริการ

1. เกี่ยวกับบริการ

FlowLanding ให้บริการออกแบบและพัฒนา:

  • เว็บไซต์และ Landing Page สำหรับธุรกิจ SME
  • ระบบ LINE Official Account และ Rich Menu
  • การจัดการเพจ Facebook (รวมถึงระบบตั้งเวลาโพสต์อัตโนมัติ)
  • ระบบ Automation และ AI Dashboard สำหรับติดตามธุรกิจ
  • เอกสารธุรกิจ (Company Profile, Catalog, Proposal ฯลฯ)

รายละเอียดขอบเขตงาน ระยะเวลาส่งมอบ และราคา จะระบุไว้ในใบเสนอราคา/สัญญาที่ตกลงกันเป็นรายกรณี ข้อกำหนดฉบับนี้ใช้เป็นเงื่อนไขทั่วไปสำหรับทุกบริการ เว้นแต่จะระบุไว้เป็นอย่างอื่นในสัญญาเฉพาะ

2. การว่าจ้างและการชำระเงิน

  • ราคาบริการอ้างอิงตามใบเสนอราคาที่ FlowLanding จัดทำให้ในแต่ละครั้ง
  • เงื่อนไขการชำระเงิน (มัดจำ/ชำระเต็มจำนวน) จะระบุไว้ในใบเสนอราคา
  • FlowLanding ขอสงวนสิทธิ์ระงับงานหากลูกค้าไม่ชำระเงินตามเงื่อนไขที่ตกลงไว้

3. ขอบเขตความรับผิดชอบ

  • FlowLanding จะดำเนินงานตามขอบเขตที่ตกลงกันด้วยความรอบคอบและเป็นมืออาชีพ
  • ลูกค้ามีหน้าที่ตรวจสอบและอนุมัติเนื้อหา/การออกแบบก่อนเผยแพร่จริง — FlowLanding ไม่รับผิดชอบต่อความเสียหายที่เกิดจากเนื้อหาที่ลูกค้าอนุมัติแล้ว
  • สำหรับระบบ Automation (เช่น ระบบตั้งเวลาโพสต์ Facebook) FlowLanding พยายามให้ระบบทำงานถูกต้องและเสถียรที่สุด แต่ไม่รับประกันว่าจะไม่มีข้อผิดพลาดทางเทคนิคที่อยู่นอกเหนือการควบคุม (เช่น การเปลี่ยนแปลงนโยบาย/ระบบของแพลตฟอร์มบุคคลที่สาม อย่าง Meta หรือ LINE)
  • FlowLanding ไม่รับผิดชอบต่อความเสียหายทางอ้อมหรือการสูญเสียผลกำไรที่เกิดจากการใช้บริการ เว้นแต่กรณีที่เกิดจากความประมาทเลินเล่ออย่างร้ายแรงของ FlowLanding เอง

4. ทรัพย์สินทางปัญญา

  • งานออกแบบ/โค้ด/ระบบที่ FlowLanding พัฒนาให้ จะโอนกรรมสิทธิ์แก่ลูกค้าเมื่อชำระเงินครบถ้วนตามที่ตกลงในสัญญา เว้นแต่ระบุไว้เป็นอย่างอื่น
  • FlowLanding ขอสงวนสิทธิ์นำผลงาน (ที่ไม่มีข้อมูลลับของลูกค้า) ไปแสดงเป็นผลงาน (Portfolio) เพื่อการตลาด เว้นแต่ลูกค้าแจ้งความประสงค์ไม่ให้เผยแพร่เป็นลายลักษณ์อักษร

5. การใช้งาน API และแพลตฟอร์มบุคคลที่สาม

บริการบางส่วนของ FlowLanding (เช่น ระบบตั้งเวลาโพสต์ Facebook, ระบบ LINE OA) เชื่อมต่อกับแพลตฟอร์มของ Meta, LINE และผู้ให้บริการอื่น การใช้บริการเหล่านี้ต้องปฏิบัติตามข้อกำหนดการใช้งานของแพลตฟอร์มนั้นๆ ด้วย (เช่น Meta Platform Terms, LINE Developers Agreement) FlowLanding ไม่รับผิดชอบต่อการเปลี่ยนแปลงนโยบายหรือการระงับบัญชีที่เกิดจากฝั่งแพลตฟอร์มบุคคลที่สามเหล่านั้น

6. การยกเลิกบริการ

  • ลูกค้าสามารถยกเลิกบริการได้ตามเงื่อนไขที่ระบุในสัญญาแต่ละฉบับ
  • FlowLanding ขอสงวนสิทธิ์ระงับหรือยกเลิกการให้บริการหากพบการใช้งานที่ผิดกฎหมาย ละเมิดข้อกำหนดของแพลตฟอร์มบุคคลที่สาม หรือสร้างความเสียหายต่อ FlowLanding

7. การเปลี่ยนแปลงข้อกำหนด

FlowLanding อาจปรับปรุงข้อกำหนดฉบับนี้เป็นครั้งคราว โดยจะแจ้งผ่านหน้านี้พร้อมวันที่ปรับปรุงล่าสุด การใช้บริการต่อหลังการปรับปรุงถือว่ายอมรับข้อกำหนดฉบับใหม่
